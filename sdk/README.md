# Klien API RPI

Contoh HTTP GET minimal tersedia untuk Python, TypeScript, PHP, Java, C#/.NET dan Dart. **Bukan paket yang sudah diterbitkan** ke npm/PyPI/Maven/NuGet/pub.dev, dan TypeScript, PHP, dan Java lulus pemeriksaan kompilasi/sintaks lokal; C# dan Dart **belum** diuji compiler maupun seluruh klien terintegrasi ke server. Seluruh API adalah baca-saja; panggil `GET /openapi.json` untuk membuat SDK bertipe dengan generator OpenAPI yang sesuai lisensi. Klien tidak memverifikasi keaslian isi statistik: selalu baca `status_verifikasi`, `jenis_data`, edisi, sumber dan catatan.
